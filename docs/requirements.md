# Cut Flow 需求文档

## 1. 文档信息

- 产品名称：Cut Flow
- 产品阶段：MVP
- 目标用户：需要持续制作短视频的独立开发者、小团队创作者
- 首要场景：将开发日志、产品更新、游戏截图或录屏制作成开发者口播短视频
- 目标平台：首期以抖音、视频号、小红书竖屏内容为主

## 2. 背景与问题

创作者通常能够提供选题、文字和原始素材，但会被脚本改写、分镜、配音、字幕、素材编排和导出等重复工作阻塞。通用剪辑软件能力强，但学习成本和逐条制作成本较高。

Cut Flow 不定位为专业剪辑器，而是一个规则驱动、可人工干预的自动视频生产系统。Codex 用于开发和迭代该系统，不直接承担剪辑器角色。

## 3. 产品目标

### 3.1 MVP 目标

输入结构化项目数据、本地图片或视频及可选旁白音频，自动生成一条 9:16、30～90 秒的口播视频，并支持浏览器预览和 MP4 导出。

### 3.2 成功指标

- 用户可在 5～10 次关键操作内完成一条基础视频。
- 首次上手 15 分钟内能替换示例素材并成功预览。
- 合法的 `project.json` 能稳定生成预期视频；非法输入能给出可定位错误。
- 缺失可选旁白时可静音预览，不崩溃。
- 示例项目可以真实导出 H.264/AAC MP4。
- 单个镜头可独立修改，未变化的生成结果可复用。

## 4. 用户画像与核心场景

### 4.1 主要用户

独立开发者或小团队成员：已有开发日志、游戏/产品截图、录屏，希望低成本持续经营账号，但缺少剪辑时间或经验。

### 4.2 核心用户故事

- 作为创作者，我希望输入开发日志后获得适合短视频的脚本和分镜。
- 作为创作者，我希望为每个镜头替换本地截图或录屏，而不用操作复杂时间轴。
- 作为创作者，我希望自动获得字幕、旁白、基础动效和转场。
- 作为创作者，我希望预览后只重做有问题的镜头，而非重做整条视频。
- 作为创作者，我希望导出视频、字幕、封面和发布文案。

## 5. 产品范围

### 5.1 MVP（P0）

1. 项目管理
   - 读取和校验 `project.json`。
   - 提供可直接运行的三镜头示例项目。
   - 保存项目标题、画布、帧率、模板、旁白和镜头列表。
2. 镜头编排
   - 按顺序呈现图片或视频素材。
   - 支持 `full-screen`、`center-card`、`split-top-bottom`。
   - 支持无动效、缓慢放大/缩小、左右平移。
   - 支持无转场和淡入淡出。
3. 字幕与音频
   - 支持整句字幕和当前句淡入。
   - 支持描边、阴影和竖屏安全区。
   - 支持本地旁白音频；缺失时降级为静音。
4. 预览与导出
   - 浏览器预览完整 Composition。
   - 导出 1080×1920、30 FPS、H.264/AAC MP4。
5. 工程质量
   - 启动和渲染前校验 Schema 及素材路径。
   - 提供类型检查、测试、lint、校验、预览和渲染命令。

### 5.2 MVP 后增强（P1）

- 图形化项目列表、脚本区、分镜卡片区、预览区、导出区。
- AI 脚本生成和严格 JSON 分镜输出。
- TTS 旁白、转录和句级/词级时间对齐。
- 本地素材库、素材元数据和基于关键词的匹配。
- `game-dev-log` 等参数化模板。
- 任务级缓存及失败重试。

### 5.3 后续能力（P2）

- AI 图片和视频生成。
- Electron 桌面封装。
- 更多平台比例、封面 PNG、SRT 和发布文案导出。
- 在线素材库、数字人、声音克隆和自动发布（需单独评估合规性）。

### 5.4 明确不做

- 类似剪映的完整多轨时间轴。
- 专业抠像、复杂关键帧和十几分钟长视频。
- AI 逐帧决定剪辑结果。
- 未经授权抓取或使用网络素材。
- MVP 阶段的账号、云端协作及全平台发布。

## 6. 核心流程

```text
创建/打开项目 → 输入或导入内容 → 形成脚本与镜头
→ 指定本地素材 → 准备旁白与字幕 → 自动计算时序
→ 合成画面/动效/转场 → 浏览器预览 → 校验 → 导出
```

MVP 从“打开结构化项目”开始；AI 生成脚本和分镜在后续阶段补齐。

## 7. 工作区需求

### 7.1 项目列表（P1）

显示封面、名称、时长、比例、状态、更新时间，并支持新建和打开项目。

### 7.2 脚本工作区（P1）

输入主题、观点、受众、时长、语气和平台；展示钩子、正文、行动引导、预计字数与时长；支持局部改写和拆镜。

### 7.3 分镜工作区（P1）

使用镜头卡片代替多轨时间轴。卡片支持替换/上传素材、调整字幕和时长、修改画面提示词、排序和锁定。

### 7.4 预览工作区（P0/P1）

MVP 提供 Remotion 预览；后续界面采用左侧镜头、中间播放器、右侧属性、底部简化时间条。

### 7.5 导出工作区（P0/P2）

MVP 输出竖屏 MP4；后续增加平台预设、封面、SRT 和发布文案。

## 8. 非功能需求

- 本地优先：核心渲染不依赖云服务或 AI API。
- 跨平台：路径处理兼容 Windows 和 macOS，Electron 封装前不引入平台耦合。
- 可恢复：单项失败应显示原因，可重试，不破坏项目数据。
- 可扩展：AI、TTS、转录和素材生成通过 Provider 接口接入。
- 可追溯：素材保存来源、授权、原始链接、创建时间和商用许可。
- 确定性：AI 只输出语义和参数，程序按规则生成帧。
- 性能：使用输入与参数哈希缓存脚本、音频、转录、素材处理和渲染结果。

## 9. MVP 验收场景

1. 使用示例项目加载 3 张图片，正确播放 3 个镜头、字幕、动效和淡入淡出。
2. 将其中一张图片替换为本地视频后仍可预览和导出。
3. 配置有效旁白文件后音频与完整视频共同导出。
4. 删除旁白文件后显示警告并静音预览；渲染过程不中断。
5. 配置不存在的必需视觉素材时，校验命令返回镜头 ID、字段和文件路径。
6. 非法布局、动效、时长或画布值被 Zod 拒绝并输出清晰错误。
7. 执行测试、类型检查、lint 和示例渲染全部通过。
