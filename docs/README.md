# Cut Flow 文档总览

Cut Flow 是一个面向开发者自媒体的本地短视频自动生产工作流。第一阶段聚焦把开发日志、截图或录屏自动合成为 30～60 秒的竖屏口播视频，而不是复刻剪映或建设通用专业剪辑器。

## 一句话目标

用户输入一段开发日志并添加截图或录屏后，在本地通过不超过 10 次关键操作，生成一条基本可发布的 9:16、30～60 秒 H.264 MP4 视频。

## 第一版边界

第一版先完成确定性的渲染闭环：结构化项目文件 → 本地素材 → 字幕与旁白 → 预览 → MP4。AI 脚本、TTS、词级字幕和素材生成在渲染内核稳定后逐步接入。
